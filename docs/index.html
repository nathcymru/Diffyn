01 / THE CONNECTION

A small server.
A more personal interaction.

The Model Context Protocol (MCP) lets an AI client use external tools, prompts and reference material.

Diffyn runs on your device, giving compatible AI clients practical ways to adapt communication to your stated preferences.

Preferences,
not assumptions.

No diagnosis needed. Choose what helps you read, plan and understand.

01

You choose the format. Explicit preferences take priority; neurotype labels do not change the settings.

02

Your meaning stays intact. Numbers, conditions and original wording matter more than a shorter answer.

03

Local by default. Diffyn makes no outbound model calls and does not save submitted text or profiles.

04 / MAKE THE CONNECTION

Your setup.
A few clear steps.

A terminal, Rust 1.99+ and an AI client
that supports local stdio MCP servers.

  1. 1

    Install Diffyn.

    Run the command to build the tagged release with Cargo.

    Need Rust? Install it first ↗
  2. 2

    Point your client to it.

    Copy the example configuration, then replace the command with the absolute path to your installed executable.

    Cargo usually installs to ~/.cargo/bin/diffyn; Windows uses diffyn.exe.

  3. 3

    Let your client connect.

    Reload the MCP configuration as your client requires, then discover Diffyn's tools, prompts and resources.

Read the connection guide ↗
Terminal / install
cargo install --git https://github.com/nathcymru/Diffyn --tag v0.1.0 --locked
Builds from source · downloads Rust dependencies during installation
MCP / example configuration
{
  "mcpServers": {
    "diffyn": {
      "command": "/absolute/path/to/diffyn",
      "args": []
    }
  }
}
Replace the path. Configuration syntax varies by client.

Local stdio only. Clients that require hosted HTTP connections need a different transport.
