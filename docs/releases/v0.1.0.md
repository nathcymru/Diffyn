# Diffyn v0.1.0

**The first packaged release of Diffyn's local Rust MCP server.**

## Included

- **Three tools:** preserve wording while adding paragraph breaks, extract supplied action sequences, and flag a defined set of English idioms.
- **Two prompts:** guide preference-led responses and focused clarification.
- **Four resources:** provide communication guidance, style options, combined preferences and evidence limits.
- **Local processing:** no outbound model calls or application-level storage of submitted text.

## Choose a download

| Platform | Archive suffix |
| --- | --- |
| Linux, x86-64; glibc 2.39 or newer | `x86_64-unknown-linux-gnu.tar.gz` |
| macOS 15 or newer, Apple silicon | `aarch64-apple-darwin.tar.gz` |
| macOS 15 or newer, Intel | `x86_64-apple-darwin.tar.gz` |
| Windows 11 or Windows Server 2025, x86-64 | `x86_64-pc-windows-msvc.zip` |

**Verify the download:** compare its SHA-256 digest with the matching entry in `SHA256SUMS` from the same release.

**Extract the archive** and set your MCP client's command to the executable's absolute path.
The [connection guide](https://github.com/nathcymru/Diffyn/blob/main/docs/engineering.md#connect-an-mcp-client) includes a configuration example.

The macOS and Windows downloads do not carry platform signing or notarization certificates.
Build from source if your device policy requires locally built software.

## Install from source

**Requires Rust 1.99 or newer.**

```sh
cargo install --git https://github.com/nathcymru/Diffyn --tag v0.1.0 --locked diffyn
```

The `.crate` attachment contains the versioned Cargo source package.
It includes the guidance embedded by the server and its dependency lockfile.

## Scope

- **Transport:** local stdio; hosted HTTP transport is not included.
- **Meaning:** formatting tools preserve original text and identify results that need review.
- **Language:** the idiom checks cover a defined English phrase set.
- **Evidence:** the release does not establish clinical effectiveness or full host-interface accessibility.

Read the [research report](https://github.com/nathcymru/Diffyn/blob/main/docs/research.md) and report vulnerabilities through the [private security form](https://github.com/nathcymru/Diffyn/security/advisories/new).
