# Diffyn v2.0.2

Diffyn 2.0.2 improves contributor onboarding and documents the next integration work. Runtime tool interfaces remain compatible with 2.0.1.

## Contributor opportunities

- Publish four bounded native plugin tasks for Claude Code, ChatGPT desktop, Mistral Vibe Code and Gemini CLI, each reusing the Rust server and a canonical skill.
- Add newcomer issue discovery to the README and contribution guide, with maintainer assistance for host checks and version reservation.
- Document contributor-directory requirements and prepare an Up For Grabs listing for separate submission.

## Roadmap

- Add an optional user-owned Cloudflare deployment and installer, covering Rust portability, authenticated remote MCP, portal configuration, selectable release channels and verified upgrades or rollback.
- Preserve the existing local installation route and require a public privacy and architecture review before remote implementation.

## Security maintenance

- Record the reviewed branch-policy, independent-review and repository-age findings as accepted present limitations, with reassessment conditions.
- Retain required checks, branch protections, weekly scanning and unmodified public Scorecard results.

These changes plan integrations and deployment work; this release does not ship the proposed plugins or Cloudflare installer.
