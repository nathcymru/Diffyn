# Diffyn v2.0.0

Diffyn 2.0.0 adds communication, planning and review workflows while retaining the local, stateless runtime. It provides **nine tools, fourteen prompts, ten guidance resources and six portable skills**.

## New capabilities

- Resolve explicit preferences across general, task and current-request scopes, with provenance and visible conflicts.
- Compare protected details in an original and revision without claiming semantic equivalence.
- Validate supplied action-plan structure and dependencies with source references.
- Build resume cards from explicit progress without storing it or inventing completed work.
- Explain supported exact arithmetic, percentages and unit conversions with labelled rounding.
- Check requested presentation constraints without a readability, capacity or cognitive-load score.

Twelve new prompts cover style choice, layered explanation, message understanding, communication repair, voice-preserving writing, task briefs, initiation, resumption, choices, numbers and dates, conversation preparation and adjustment requests. The two original prompt IDs remain available; focused clarification replaces the interrogator's displayed title.

Six self-contained skills are available as portable folders and through the MCP Skills extension. Ten embedded resources document the operational rules, host boundaries and evidence-to-feature mapping.

## Existing tools

Checklist results now carry source revisions, stable step IDs, explicit progress, a complete source list and movable unfinished display windows. Protected-span handling lets eligible surrounding prose be processed while retaining source code and other protected material. Clarity checking adds optional bounded time and reference rules, language declarations and explicit coverage.

## Compatibility

The original tool names, prompt identifiers, four guidance URIs and optional profile fields remain. Checklist active-window semantics and result schemas have changed; consumers should read the [migration guide](../migration-v2.md). New tools use their own published schemas rather than accepting the legacy profile object indiscriminately.

## Evidence and scope

The research synthesis adds primary studies of neurodivergent LLM use, authorship, task support, reciprocal communication and stereotype risks. These inform design and failure cases; they do not establish Diffyn's clinical effectiveness or accessibility conformance. The server makes no model calls, stores no submitted state and does not control host rendering or retention.
