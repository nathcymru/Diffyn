---
title: "Why does “Organise my move” return insufficient structure?"
category: q-a
---

**The checklist extracts explicit steps; it does not invent a complete plan from a broad goal.**

This maintainer-written FAQ explains `insufficient_structure`.

“Organise my move” does not establish the dates, location, equipment or prerequisites.
The local tool therefore returns empty step arrays and identifies missing information rather than presenting guessed actions as extracted facts.

## Useful next steps

- **Provide existing actions:** supply a numbered list if you already have a sequence.
- **Clarify one gap:** the host can ask the smallest useful question about your goal.
- **Label suggestions:** a host model may propose a sequence, but it should distinguish those suggestions from your original information.
- **Review dependencies:** check consequential unknowns before relying on a plan.

The [adaptive clarification prompt](https://github.com/nathcymru/Diffyn/blob/main/docs/prompts/adaptive-interrogator.md) helps the host approach that conversation without a long questionnaire.
