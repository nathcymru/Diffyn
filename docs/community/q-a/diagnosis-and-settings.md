---
title: "Do I need a diagnosis or neurotype label to use Diffyn?"
category: q-a
---

**No.** The tools work without a diagnosis, age disclosure or neurotype label.

This maintainer-written FAQ explains the current behavior.

## How preferences work

The optional `profile.preferences` object selects explicit settings such as paragraph grouping, checklist size and generated emphasis.
Omitting the profile uses neutral product defaults.

- **Labels are optional:** `self_declared_neurotypes` can be omitted.
- **No hidden preset:** adding a label does not change the tool's settings.
- **Your request matters:** host-level preferences such as tone or explanation order can be expressed in ordinary language.

For example, “Use plain text and keep the full sequence available” is a useful preference without any personal explanation.

See the [supported preferences](https://github.com/nathcymru/Diffyn/blob/main/docs/communication-contract.md#supported-preferences) for the exact tool fields.
Follow-up questions are welcome, with no diagnostic disclosure needed.
