**Imagine arriving at the project for the first time.** Which resource would give you the most useful starting point?

The options can complement each other; this poll asks which one you would open first.

## Optional participation

- **Pick one starting point:** choose the resource closest to your immediate need.
- **Add a missing option:** mention another format in a comment if you want.
- **Keep details private:** no account, workplace or health information is needed.

Responses can inform documentation discussion without promising a particular change or date.
