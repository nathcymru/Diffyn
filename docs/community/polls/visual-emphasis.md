**Think about a short practical guide with several sections.** The wording would stay the same across formats.

This question is about your preferred presentation, not a claim that one style improves reading for everyone.

## Optional participation

- **Choose the closest fit:** use the option you would try first.
- **Describe an alternative if useful:** one sentence is enough.
- **Skip any explanation:** there is no need to justify a preference.

The host interface still controls fonts, colours and spacing.
