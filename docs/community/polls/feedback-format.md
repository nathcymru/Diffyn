title: "Which feedback format would be easiest to use?"
category: polls
---

**Imagine noticing one confusing part of Diffyn.** Which format would make it easiest to explain that problem?

This is about reducing the effort of contributing feedback, not testing anyone's writing ability.

## Optional participation

- **Choose a format:** select the route you would be most likely to use.
- **Offer another approach:** a short comment is welcome.
- **Share no sensitive data:** use synthetic examples if you add details.

Voting is optional, and a preferred format does not create an obligation to contribute.
