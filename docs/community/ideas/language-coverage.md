---
title: "Idea: make language coverage easier to understand"
category: ideas
---

**Proposal for discussion:** make each tool's language limits clearer at the point where a host uses its result.

The clarity tool checks finite English phrase rules and now reports the declared language, supported coverage, applied categories and analyzed bytes. Unsupported languages receive an explicit warning without analysis. The host still needs to explain that result clearly.
The checklist recognizes some English and Welsh sequencing patterns, while text preservation does not imply broad language understanding.

## Further improvements to explore

- **A concise label:** present the returned language coverage beside the result.
- **Specific warnings:** distinguish unrecognized structure from a failure to understand the person's goal.
- **Small examples:** show the same task in supported and unsupported forms.
- **Regression cases:** preserve meaningful punctuation and wording when recognition is uncertain.

The aim would be honest expectations, not a claim that every language has been validated.
