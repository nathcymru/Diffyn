**Proposal for discussion:** a client-specific guide could reduce the gap between building Diffyn and using it in a real workflow.

The current server uses local stdio.
A guide would need to verify the chosen client's actual configuration and avoid promising compatibility that has not been tested.

## A useful guide would show

- **Prerequisites:** the operating system and client version used.
- **Configuration:** where to place the executable's absolute path.
- **A small check:** one synthetic request and the expected kind of result.
- **Troubleshooting:** a redacted error example and a clear next step.

Hosted HTTP integration would require additional implementation, not just different instructions.

Which client and operating system would make a guide useful to you?
