---
title: "Idea: preview a preference before applying it"
category: ideas
---

**Proposal for discussion:** a small preview could show how a formatting choice changes synthetic text before someone uses it on their own material.

This is an idea, not an announced feature or delivery commitment.

## Possible shape

- **One choice:** change paragraph grouping or generated emphasis.
- **Visible comparison:** keep the original and reformatted text available.
- **Reversible action:** let the person return to the previous view.
- **Clear scope:** explain which settings affect the local tool and which belong to the host.

A useful preview would preserve wording and avoid treating one presentation as the correct choice for a neurotype.

## Useful feedback

Which single preference would be most helpful to preview, and what would you need to see to judge it?
A one-line answer is welcome.
