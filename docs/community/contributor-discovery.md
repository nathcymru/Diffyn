# Contributor discovery

**Start with one [good first issue](https://github.com/nathcymru/Diffyn/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22).** The initial native plugin tasks reuse Diffyn's Rust server and one existing skill. Their briefs identify the files to inspect, suggested steps, expected results and checks for completion.

Questions and partial progress are welcome. Contributors can request a maintainer's client check when platform access is unavailable; offline packaging and protocol checks do not require paid model calls. Follow the [contribution guide](../../.github/CONTRIBUTING.md), including sharing a proposed branch before the maintainer reserves its PR version.

## Keep beginner tasks useful

- Keep each task independent of a larger redesign or unpublished service.
- State the supported host, prerequisites and tested operating systems.
- Give a small first step and a clear completion checklist.
- Link the existing implementation and current official platform documentation.
- Respond to questions and review submitted work without requiring a fixed work schedule.
- Remove the beginner label if investigation reveals a substantially larger task.

The [Cloudflare installer proposal](https://github.com/nathcymru/Diffyn/issues/45) involves authentication, remote transport, release verification and deployment operations. It is tracked separately from the beginner tasks.

## Directory listings

**Up For Grabs:** submit the [prepared listing](diffyn-up-for-grabs.yml) as `_data/projects/diffyn.yml` in the directory's repository, following its [listing instructions](https://github.com/up-for-grabs/up-for-grabs.net/blob/gh-pages/docs/list-a-project.md). The listing uses the existing `good first issue` label. Confirm that the labelled issues remain open and suitable, then record the submission and its outcome. Inclusion requires a reviewed external pull request; a local listing file does not publish the project.

**goodfirstissue.dev:** its [submission requirements](https://github.com/DeepSourceCorp/good-first-issue/blob/master/README.md#adding-a-new-project) currently include at least three beginner-labelled issues and ten contributors, alongside setup instructions, contribution guidance, active maintenance and an open-source licence. Check the current contributor count before using its submission form. Creating labels does not automatically list the repository.

Review directory requirements before submission because eligibility and submission processes can change. Do not promise listing or directory approval in contributor-facing material.
