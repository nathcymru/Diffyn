---
title: "What local processing means for your privacy"
category: announcements
---

**Diffyn processes text in its local server process.** It does not make outbound model calls, save profiles or log submitted content at the application level.

That boundary does not cover the AI client you connect to it.
A host may use a cloud model or retain the conversation under its own policies.

## Before sharing an example

- **Use only what is needed:** a short synthetic passage is usually enough to show a formatting problem.
- **Remove identifying details:** avoid posting private conversations, health records or credentials.
- **Check the destination:** GitHub discussions and ordinary issues are public.

## Where to report a security problem

Use the [private vulnerability reporting route](https://github.com/nathcymru/Diffyn/security/advisories/new) rather than a public discussion.

The [security policy](https://github.com/nathcymru/Diffyn/blob/main/.github/SECURITY.md) and [engineering guide](https://github.com/nathcymru/Diffyn/blob/main/docs/engineering.md#privacy-boundary) explain the limits, including process memory and host retention.
