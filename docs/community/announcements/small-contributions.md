title: "Small contributions that make Diffyn easier to use"
category: announcements
---

**A useful contribution can be small.** You do not need to write Rust to improve Diffyn.

## Ways to help

- **Clarify a sentence:** point to wording that is hard to understand and suggest an alternative.
- **Improve an example:** show a synthetic input and the result you expected.
- **Check navigation:** identify a confusing heading, link or setup step.
- **Review a source:** distinguish what the evidence supports from a product preference.

## Give one concrete example

A short report can use this structure:

> I was trying to …
>
> I reached …
>
> I expected …

Share only the detail needed to explain the problem.
Screenshots and diagnostic information are optional unless they are necessary to reproduce a specific issue.

The [contribution guide](https://github.com/nathcymru/Diffyn/blob/main/.github/CONTRIBUTING.md) explains where to send changes and which checks apply.
