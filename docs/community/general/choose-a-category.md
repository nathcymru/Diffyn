**Choose the closest category; a perfect label is not required.** This guide helps keep conversations easy to find.

## Discussion categories

- **Announcements:** project information and maintainer updates.
- **General:** communication preferences, questions about the community and open conversation.
- **Ideas:** a problem and a possible improvement to explore.
- **Q&A:** a specific question that can have a useful answer.
- **Show and tell:** an example, integration or experiment with its limits explained.
- **Polls:** a small choice about how people want to use or understand the project.

## Other routes

Use an [issue](https://github.com/nathcymru/Diffyn/issues/new/choose) for a reproducible bug or a concrete feature request.
Use the [private security route](https://github.com/nathcymru/Diffyn/security/advisories/new) for vulnerabilities.

A post can be brief, and you never need to disclose a diagnosis to explain a preference or barrier.
