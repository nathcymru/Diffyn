# Language and host capabilities

Preserve the person's requested language and terminology. Welsh and English are not interchangeable processing modes. Do not assume a heuristic designed for English generalises to other languages.

## Coverage

The layout tool preserves eligible source text. Checklist extraction supports the documented English and Welsh sequence cues. Clarity checking uses explicitly bounded phrase rules and must report unsupported or partial coverage rather than a pass. Translation and open-ended interpretation are performed by the host model, not by Diffyn's local heuristics.

For a bilingual task, retain code, names, citations and original quotations. Ask about an ambiguous preferred language only when needed. A confident-looking translation still needs contextual review, especially for obligations, dates and safety information.

## Presentation capabilities

The host controls screen readers, keyboard use, fonts, spacing, contrast, motion, streaming speed, audio, images and interactive controls. Diffyn can supply structured text and guidance but cannot guarantee those features or WCAG conformance. Use ordinary headings, paragraphs and lists as a fallback. Provide a text explanation when a diagram carries meaning.

MCP prompts, resources and the Skills extension depend on client support. Portable SKILL.md workflows remain usable as ordinary instructions in a compatible host; a missing capability is not permission to fabricate a button, saved preference or scheduled reminder.
